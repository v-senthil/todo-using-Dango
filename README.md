# To-Do (Django)

Basic to-do list app used to learn Django's model/view/template flow.

## How it works
- `tasks` app defines a `Task` model (`title`, `complete`, `created`) with a form and views to list, add, toggle and delete items.

## Use
1. `pip install django`
2. `python manage.py migrate`
3. `python manage.py runserver`

College project, 2019–2021.
